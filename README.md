# Virtual Assistant with Smart UI for Agricultural Support

## Project Overview
The Virtual Assistant with Smart UI for Agricultural Support is an AI-powered application designed to help farmers access agricultural information easily. It combines an interactive user interface, an AI chatbot, and image analysis to provide farming guidance and support crop disease identification.

## Key Features
- **AI Chat Assistant:** Provides answers to agriculture-related queries.
- **Crop Disease Detection:** Analyzes uploaded plant images using a YOLO-based model.
- **Smart Dashboard:** Displays image analysis results and detection history.
- **Visual Analytics:** Presents detection records and statistics in an organized format.
- **User-Friendly Interface:** Simplifies access to agricultural information and analysis.

## Technologies Used
- Python
- Llama 3.2
- YOLO
- llama.cpp
- HTML, CSS, and JavaScript

## How It Works
1. Users enter agricultural questions through the AI chat interface or upload plant images for analysis.
2. The language model processes text queries and generates relevant responses.
3. The YOLO-based image processing module analyzes uploaded images and identifies visual patterns associated with crop diseases.
4. The dashboard displays the results and maintains detection history for reference.
